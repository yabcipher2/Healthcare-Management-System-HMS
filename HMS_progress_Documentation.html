📱 HMS Project Pages Documentation

1️⃣ Landing Page
Main entry point of the Healthcare Management System. Displays welcome message, system overview, and navigation to all modules. Professional design with quick access to login.
Features:
  • System Overview
  • Quick Navigation
  • Login Portal
  • Module Descriptions
📊 Demo/Overview Page
Interactive demonstration page showing all available features and modules. Provides sample data and tutorials for new users to understand system functionality.
Features:
  • Feature Showcase
  • Interactive Demos
  • Sample Data
  • Tutorial Guides
Admin Dashboard Page
Full Admin controle dashboard for managing all aspects of the healthcare system. Admins can manage users, view system analytics, configure settings, and oversee operations across all modules. Comprehensive admin interface for complete system control.
Features:
  • Feature Showcase
  • Interactive Demos
  • Sample Data
  • Tutorial Guides
2️⃣ Doctor Dashboard
Doctor's main interface for managing patient appointments, medical records, prescriptions, and patient schedules. View upcoming appointments and patient history.
Features:
  • Manage Appointments
  • View Medical Records
  • Write Prescriptions
  • Patient Schedule
3️⃣ Laboratory Dashboard
Laboratory management system for handling test requests, managing test results, and tracking lab samples. View test status and generate reports.
Features:
  • Test Requests
  • Results Management
  • Sample Tracking
  • Report Generation
4️⃣ Login Page
Secure authentication page for all users. Login with username/email and password. JWT-based authentication system for secure access to HMS modules.
Features:
  • Secure Authentication
  • JWT Token System
  • Password Validation
  • Error Handling
5️⃣ Pharmacy Dashboard
Pharmacy management system for handling prescriptions, managing drug inventory, and dispensing medications. Track medication stock and process prescriptions.
Features:
  • Prescription Processing
  • Inventory Management
  • Drug Stock Tracking
  • Medication Dispensing
6️⃣ Reception Page
Reception desk interface for patient check-in, appointment scheduling, and patient registration. Manage patient arrivals and schedule appointments.
Features:
  • Patient Check-in
  • Appointment Scheduling
  • Patient Registration
  • Visitor Management
7️⃣ Triage Page
Triage system for patient assessment and vital signs recording. Prioritize patients based on urgency and medical condition for appropriate care routing.
Features:
  • Vital Signs Recording
  • Patient Assessment
  • Priority Ranking
  • Care Routing
